# PVA2 - Programování a vývoj aplikací
## Cvičení 10: Funkce - pokročilé

### Jak řešit
- Cvičení má čtyři úkoly, každý v samostatném souboru. Zadání úkolu je v Markdown souboru s odpovídajícím názvem.
- **Název funkce, parametry i jejich datové typy opište přesně ze zadání.** Podle nich se řešení automaticky vyhodnocuje.
- Každá funkce má typové anotace parametrů i návratové hodnoty.
- Funkce výsledek **vrací** přes `return`. Načtení vstupu (`input()`) a výpis (`print()`) patří do hlavního programu pod funkcemi.
- Po každém `git push` se řešení vyhodnotí a výsledek najdete v pull requestu **Feedback**. Požadavky jsou očíslované podle úkolů: A1, A2, … u úkolu A atd.
